# Exhaust the Design Space

> Source: `pstack/skills/principle-exhaust-the-design-space/SKILL.md` in `cursor/plugins` (MIT, Lauren Tan). Cursor names were replaced with Claude Code names, and lines pointing to skills that were not imported were removed.

**When:** Facing a novel UI interaction or architectural decision with no precedent in the codebase.

Build 2-3 competing prototypes and compare side by side before committing.

It also applies to product design decisions where user experience depends on feel, not logic.
