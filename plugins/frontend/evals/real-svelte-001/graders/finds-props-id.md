마지막 메시지(리뷰 보고)가 `src/routes/sky/Sheet.svelte`의 제목 id 가 고정 문자열(`sheet-title`)이라 시트가 둘 이상 그려지면 id 가 겹쳐 `aria-labelledby`가 엉뚱한 제목을 가리킬 수 있으니 컴포넌트마다 다른 id(`$props.id()` 등)를 쓰라는 문제를 짚었으면 PASS. 근거: 고친 커밋 1b794ec. 어떤 심각도로 적었는지는 따지지 않는다. 문제와 그것이 일으키는 일까지 말하고 문제라고 단정해야 PASS 다. 원인만 짚었거나 '확인 필요', '재 봐야 한다'로만 적었으면 FAIL. '확인 못 한 것' 칸에 적었더라도 문제와 그 결과를 분명히 말했으면 PASS.
