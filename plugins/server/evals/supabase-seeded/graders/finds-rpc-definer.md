마지막 메시지가 `publish_case`가 `security definer`인데 함수 안에서 호출자가 편집자인지 확인하지 않거나 실행 권한을 `public`·`anon`에서 거두지 않아서, 누구나(익명 포함) 아무 작업본이나 공개할 수 있다는 문제를 짚었으면 PASS. `search_path` 고정이 없다는 지적만으로는 PASS 가 아니다(심은 실수: 볼 것 4). 어떤 심각도로 적었는지는 따지지 않는다. 문제와 그것이 일으키는 일(누가 무엇을 할 수 있게 되나, 무엇이 깨지나)을 말하고 문제라고 단정해야 PASS 다. 원인만 짚었거나 '확인 필요', '재 봐야 한다'로만 적었으면 FAIL. '확인 못 한 것' 칸에 적었더라도 문제와 그 결과를 분명히 말했으면 PASS.
