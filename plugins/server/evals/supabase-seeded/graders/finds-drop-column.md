마지막 메시지가 마이그레이션이 `published_cases.published_at`을 지우고 기본값 없는 `not null` 열(`published_on`)을 더해서, 기존 공개본의 날짜가 사라지거나 행이 있으면 마이그레이션이 실패한다는 문제를 짚었으면 PASS(심은 실수: 볼 것 10). 어떤 심각도로 적었는지는 따지지 않는다. 문제와 그것이 일으키는 일(누가 무엇을 할 수 있게 되나, 무엇이 깨지나)을 말하고 문제라고 단정해야 PASS 다. 원인만 짚었거나 '확인 필요', '재 봐야 한다'로만 적었으면 FAIL. '확인 못 한 것' 칸에 적었더라도 문제와 그 결과를 분명히 말했으면 PASS.
