# Fix Root Causes

> 원문: `cursor/plugins`의 `pstack/skills/principle-fix-root-causes/SKILL.md` (MIT, Lauren Tan). Cursor 이름을 Claude Code 것으로 바꾸고 가져오지 않은 스킬을 가리키는 줄을 뺐다.

**언제:** 디버깅할 때. 증상마다 시스템이 처음 잘못된 곳까지 거슬러 올라가 거기서 고친다. 가드는 그것이 다루는 상태가 정당할 때만 수정이다.

증상이 드러난 곳이 아니라 결함을 고친다. 근본 원인은 시스템이 하면 안 되는 일을 처음 한 곳, 또는 처리해야 할 상태를 처음 처리하지 못한 곳이다.

- 먼저 재현한다. 답이 코드 안의 잘못된 결정이 될 때까지 "왜"를 묻는다. 막히면 계측을 넣고 실제 상태를 읽는다.
- 증상을 일으킨 상태가 정당한 상태인지 묻는다. 정당하면 코드가 깨진 곳에서 처리한다. 있어서는 안 되는 상태라면 거기에 넣은 검사는 버그를 가리므로, 그 상태를 만든 것을 찾는다. 가드, 재시도, 삼킨 오류, 범위 안으로 잘라 맞춘 값, 버린 상태가 버그를 가리는 흔한 방법이다.
- 한 건이 아니라 패턴을 고친다. 같은 결함이 있는 곳을 모두 찾는다.
- 결정적인 사실을 깊이 파고서야 찾았다면, 처음 봤을 때 그것을 보여 줬을 값싸고 늘 켜져 있는 신호를 제안한다.
