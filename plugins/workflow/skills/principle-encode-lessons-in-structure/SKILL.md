# Encode Lessons in Structure

> 원문: `cursor/plugins`의 `pstack/skills/principle-encode-lessons-in-structure/SKILL.md` (MIT, Lauren Tan). Cursor 이름을 Claude Code 것으로 바꾸고 가져오지 않은 스킬을 가리키는 줄을 뺐다.

**언제:** 같은 지시를 두 번째로 쓰고 있거나, 같은 교정이 되풀이되는 것을 알아챘을 때.

그 규칙을 글로 더 쓰지 말고 린트, 메타데이터 플래그, 런타임 검사, 스크립트로 옮긴다.

교훈에 판단이 필요해서 구조로 옮길 수 없으면, 지시를 더 눈에 띄게 하고 그 실패 유형의 예를 하나 붙인다.

**따름 규칙:** 고칠 방법이 구조적이면 구조적인 수정만 쓴다. 지시는 증상이다.
