# 작업 시작

프로젝트의 CLAUDE.md·AGENTS.md 에 작업 규칙이 있으면 그쪽이 이 스킬보다 우선한다. 백로그 위치와 형식은 `backlog-create` 스킬을 따른다(기본 `docs/backlog.md`, 상세는 `docs/backlog/<ID>.md`).

## 1. 무엇을 할지 정한다

- **ID 를 받았으면** 그 항목을 연다.
- **설명만 받았고 백로그에 없는 일이면** 바로 시작하지 말고 `backlog-create` 로 항목부터 만들지 묻는다. 작은 일이라 백로그 없이 하겠다고 하면 2로 넘어간다.
- **아무것도 안 받았으면** 다음 항목을 추천한다. Now → Backlog → Bugs 순서로, 섹션 안에서는 위가 먼저다. Inbox, 열린 질문이 남은 항목, 선행 항목이 안 끝난 항목은 건너뛰고, 건너뛴 이유를 같이 보여 준다.
- **어느 항목을 할지는 사용자가 정한다.** 추천만 하고 확인을 받는다. 확인 없이 고르지 않는다.

## 2. 준비됐는지 본다

1. 상세 파일을 읽는다. 수용 기준이 없거나 열린 질문이 남아 있으면 무엇이 빠졌는지 말하고 채울지 묻는다. 채워지기 전에는 시작하지 않는다.
2. 이미 `[~]` 진행 중인 항목이면 새로 시작하지 않고 이어서 한다. 상세 파일의 `## 인계` 메모와 지금 브랜치 상태를 읽고 남은 일부터 한다.

## 3. 스택을 판별한다

CLAUDE.md 의 `stack:` 을 먼저 본다. 없으면 추정한다.

- `supabase/` 폴더 → supabase
- package.json 에 react·next·vue·svelte 등 → frontend
- express·nest·fastify·fastapi·django·spring 등 → server

**여러 개면 5의 해당 섹션을 전부 적용한다.** 판별 결과를 한 줄로 알린다.

## 4. 브랜치와 표시

1. 기준 브랜치를 정한다. CLAUDE.md 에 있으면 그것, 없으면 `develop` 이 있으면 `develop`, 없으면 원격 기본 브랜치.
2. `git fetch --prune`. 미커밋 변경이 있으면 멈추고 어떻게 할지 묻는다.
3. 같은 이름의 브랜치가 이미 있으면(다른 기기에서 시작했을 수 있다) 새로 만들지 않고 그 브랜치로 이어 간다. 없으면 기준 브랜치 최신 커밋에서 `<type>/<ID>-<영문-kebab>` 로 만든다. type 은 `feat|fix|refactor|chore|docs|test|perf`.
4. 의존성을 설치한다(lockfile 에 맞는 패키지 매니저).
5. 백로그에서 항목을 `[~]` 로 바꾸고 Now 에 그 항목을 가리키는 줄을 넣는다. 이 변경은 따로 커밋하지 않고 작업 커밋에 같이 들어간다.

## 5. 스택별 사전 점검 (해당하는 것 전부)

각 항목은 하거나, 해당 없으면 이유를 한 줄 남기고 건너뛴다.

### frontend
- 만들기 전에 재사용할 것을 찾는다. 공용 컴포넌트·디자인 시스템에서 화면 요소마다 맞는 것을 표로 정리하고, 없는 것은 플랜에 "새로 만듦"으로 적는다.
- 시안이나 기획 링크가 없으면 묻는다. 없다고 하면 무엇을 기준으로 삼을지 플랜에 적는다.

### supabase
- 로컬 DB 가 최신 마이그레이션까지 적용됐는지 확인한다. 어긋나면 알리고 멈춘다.
- 스키마가 바뀌는 작업이면 플랜에 마이그레이션 파일, 타입 재생성, RLS 정책을 넣는다. 새 테이블은 RLS 를 켜고 정책을 같이 만든다.
- service role 키는 클라이언트 코드에 두지 않는다.

### server
- 바뀌는 API 가 있으면 요청·응답 형식의 변경점과 이를 쓰는 쪽을 플랜에 적는다.
- 로컬에서 서버가 뜨는지, 필요한 환경변수가 있는지 확인한다. 없는 값은 이름만 알리고 값을 대화에 붙여 달라고 하지 않는다.

## 6. 플랜

`EnterPlanMode` 로 플랜을 세워 승인받은 뒤 작업한다. 플랜은 수용 기준마다 무엇을 바꾸고 어떻게 확인할지로 짠다. 모르는 것은 지어내지 않고 묻는다.

## 지킬 것

- 한 번에 한 항목만 진행한다.
- 작업 도중 세션이 끝날 것 같으면 상세 파일 끝에 `## 인계` 를 남긴다: 한 것, 남은 것, 건드린 파일, 마지막 확인 결과, 다음 행동.
