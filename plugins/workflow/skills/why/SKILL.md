# Why

> 원문: `cursor/plugins`의 `pstack/skills/why/SKILL.md` (MIT, Lauren Tan). Cursor 이름을 Claude Code 것으로 바꾸고 가져오지 않은 스킬을 가리키는 줄을 뺐다.

**언제:** "X 는 왜 이렇게 동작하나", "왜 Y 를 골랐나", 설계 근거, 회귀, 사후 분석, 데이터로 정한 임계값을 물을 때 쓴다. 결정과 trade-off 를 출처와 함께 돌려준다. 실행 중 동작은 `how` 스킬을 쓴다.

코드가 아니라 기록으로 답한다. 대상을 처음 넣은 변경과 그 뒤의 변경마다 커밋과 PR 논의를 읽는다. 흔적이 얇으면 다른 자료도 읽는다. 작성자가 쓴 말을 인용하고, 자기 추론은 추론이라고 표시하고, 기록이 답하지 않는 것을 말한다.
