# Fix merge conflicts

> 원문: `cursor/plugins`의 `cursor-team-kit/skills/fix-merge-conflicts/SKILL.md` (MIT, Cursor). Cursor 이름을 Claude Code 것으로 바꾸고 가져오지 않은 스킬을 가리키는 줄을 뺐다.

**언제:** 브랜치에 풀리지 않은 머지 충돌이 있을 때. 묻지 않고 충돌을 풀고, 빌드와 테스트로 확인하고, 충돌 해결을 마무리한다.

## 계기

브랜치에 풀리지 않은 머지 충돌이 있고, 빌드되는 상태까지 가는 믿을 만한 길이 필요하다.

## 순서

1. git status 와 충돌 표시로 충돌한 파일을 모두 찾는다.
2. 충돌마다 정확성을 앞세운 최소한의 수정으로 푼다.
3. 안전하면 양쪽을 다 살린다. 아니면 컴파일되고 공개 동작이 그대로인 쪽을 고른다.
4. 잠금 파일은 손으로 고치지 말고 패키지 관리자 도구로 다시 만든다.
5. 컴파일, 린트, 관련 테스트를 돌린다.
6. 푼 파일을 스테이징하고 주요 결정을 요약한다.

## 지킬 것

- 변경은 작고 읽기 쉽게 둔다.
- 어느 파일에도 충돌 표시를 남기지 않는다.
- 충돌을 푸는 동안 넓은 리팩터링을 하지 않는다.
- 충돌을 푸는 동안 푸시하거나 태그를 달지 않는다.

## 출력

- 푼 파일
- 눈에 띄는 해결 선택
- 빌드/테스트 결과
