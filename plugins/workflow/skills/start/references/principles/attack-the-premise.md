# Attack the Premise

> 원문: `cursor/plugins`의 `pstack/skills/principle-attack-the-premise/SKILL.md` (MIT, Lauren Tan). Cursor 이름을 Claude Code 것으로 바꾸고 가져오지 않은 스킬을 가리키는 줄을 뺐다.

**언제:** 같은 전제를 깔고 있는 수정이 둘 이상 같은 관문(통과해야 하는 검사)에서 실패했을 때.

같은 전제를 깔고 있는 수정이 둘 이상 같은 관문에서 실패하면, 수정이 아니라 전제를 의심한다.

- 전제를 적는다. 실패한 수정이 모두 가정한 한 문장이다.
- 다음 수정 전에 전제를 시험한다. 전제가 틀렸다면 결과가 달라질 관찰을 찾아 직접 해 본다. 실패가 얼마나 큰지만 보지 말고 어떻게 분포하는지도 본다.
- 증거가 전제와 어긋나면, 전제는 예측하지 못했는데 실패들이 공유하는 것을 찾는다. 어느 한 부분이 늘 지는 쪽에 놓이면, 뒤처리하는 장치를 더하지 말고 그 부분을 거기에 놓는 것을 바꾼다.

전제를 적고 시험하기 전에는 다음 수정을 시작하지 않는다.
