# Foundational Thinking

> 원문: `cursor/plugins`의 `pstack/skills/principle-foundational-thinking/SKILL.md` (MIT, Lauren Tan). Cursor 이름을 Claude Code 것으로 바꾸고 가져오지 않은 스킬을 가리키는 줄을 뺐다.

**언제:** 로직을 쓰기 전에. 핵심 타입과 자료 구조를 고를 때, 뼈대 작업과 기능 작업의 순서를 정할 때, 동시에 도는 행위자들이 무엇을 공유하는지 따질 때다. 자료 구조가 맞으면 그 뒤의 코드는 뻔해진다.

로직을 쓰기 전에 데이터의 모양을 맞춘다. 핵심 타입을 일찍 정의하고, 접근 패턴을 하나하나 따라가 보고, 가장 많이 쓰이는 경로에 맞는 구조를 고른다. 줄 하나하나가 아니라 구조의 중복을 없앤다(DRY).

행위자들이 상태를 공유하게 하기 전에, 다른 행위자가 동시에 그 상태를 바꾸면 어떻게 되는지 묻는다. 답이 "아무 일도 없다"가 아니면 격리한다.

뼈대를 먼저 세운다. 뒤의 모든 단계를 돕는 것(CI, 테스트, 공유 타입)은 죽은 코드를 지운 다음 맨 먼저 한다. 커밋은 작게, 목적 하나로 유지한다.
