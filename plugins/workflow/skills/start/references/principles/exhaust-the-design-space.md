# Exhaust the Design Space

> 원문: `cursor/plugins`의 `pstack/skills/principle-exhaust-the-design-space/SKILL.md` (MIT, Lauren Tan). Cursor 이름을 Claude Code 것으로 바꾸고 가져오지 않은 스킬을 가리키는 줄을 뺐다.

**언제:** 코드베이스에 선례가 없는 새로운 UI 상호작용이나 아키텍처 결정을 마주했을 때.

확정하기 전에 경쟁하는 프로토타입을 2-3개 만들어 나란히 비교한다.

사용자 경험이 논리가 아니라 느낌에 달린 제품 디자인 결정에도 적용한다.
