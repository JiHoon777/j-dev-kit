# Type System Discipline

> 원문: `cursor/plugins`의 `pstack/skills/principle-type-system-discipline/SKILL.md` (MIT, Lauren Tan). Cursor 이름을 Claude Code 것으로 바꾸고 가져오지 않은 스킬을 가리키는 줄을 뺐다.

**언제:** 타입을 설계할 때, 함수 시그니처를 리뷰할 때, 정적 타입 언어로 코드를 쓸 때. 잘못된 상태를 표현할 수 없게 하고, 뜻이 있는 원시 값에 브랜드를 붙이고, 외부 데이터는 경계에서 파싱하고, 변형(variant)을 빠짐없이 처리하고, 권위 있는 스키마에서 타입을 끌어낸다.

불가능한 상태, 서로 뒤바뀐 원시 값, 처리하지 않은 변형을 컴파일러가 거부하게 만든다.

- **뜻이 있는 원시 값에는 브랜드를 붙인다.** 두 인자가 원시 타입은 같은데 뜻이 다르면 각각 자기 타입을 준다. 만들 때 한 번 검증한다.
- **외부 데이터는 파싱하기 전까지 타입이 없다.** JSON, RPC 페이로드, CLI 인자, 설정, 환경 변수, 데이터베이스 행은 경계에서 파싱 함수를 거치고, 그 함수가 타입이 있는 모델을 돌려준다.
- **권위 있는 스키마에서 타입을 끌어낸다.** 스키마 파일이 어떤 모양의 주인이면, 손으로 같은 것을 하나 더 만들지 말고 거기서 타입을 끌어낸다.
