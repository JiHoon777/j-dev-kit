# Make Operations Idempotent

> 원문: `cursor/plugins`의 `pstack/skills/principle-make-operations-idempotent/SKILL.md` (MIT, Lauren Tan). Cursor 이름을 Claude Code 것으로 바꾸고 가져오지 않은 스킬을 가리키는 줄을 뺐다.

**언제:** 크래시, 재시작, 재시도 속에서 도는 명령, 수명 주기 단계, 처리 루프를 설계할 때. 앞선 실행이 어디까지 했든 같은 최종 상태로 수렴하게 한다.

상태를 바꾸는 모든 작업은 몇 번을 돌든, 앞선 실행이 어디서 멈췄든 올바른 상태로 수렴하게 설계한다.

각 단계는 앞선 실행이 하려던 일이 아니라 지금 있는 상태에서 끌어낸다. 현재 상태를 읽고, 목표와 비교하고, 차이만 적용한다.

실행이 남기는 것(락, 임시 파일, 쓰다 만 레코드, 선점한 작업)은 다음 실행이 낡은 것임을 알아볼 수 있어야 한다. 그 근거는 앞선 실행이 어디서 멈췄든 성립하는 증거여야 한다. 임시 경로에 쓰고 rename 으로 제자리에 옮긴다.

시험: 이것이 두 번 돌면 어떻게 되나? 앞선 실행이 가능한 모든 지점에서 죽었다면 어떻게 되나? 답이 남겨진 것에 따라 달라지면 조정(reconciliation) 단계를 넣는다.
