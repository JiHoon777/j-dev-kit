마지막 메시지가 Edge Function `notify-editors`가 호출자를 확인하지 않거나(JWT·웹훅 비밀 확인 없음), service role 키를 `console.log`로 로그에 남기거나, 받은 본문을 응답에 그대로 돌려준다는 문제 가운데 하나라도 짚었으면 PASS(심은 실수: 볼 것 9). 어떤 심각도로 적었는지는 따지지 않는다. 문제와 그것이 일으키는 일(누가 무엇을 할 수 있게 되나, 무엇이 깨지나)을 말하고 문제라고 단정해야 PASS 다. 원인만 짚었거나 '확인 필요', '재 봐야 한다'로만 적었으면 FAIL. '확인 못 한 것' 칸에 적었더라도 문제와 그 결과를 분명히 말했으면 PASS.
