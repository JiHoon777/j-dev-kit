## Description

지금은 일을 맡겨도 `/task`, `/lead`, `/ui`의 질문 지점(계획 승인, 리뷰 지적 결정, 머지 승인, 시안 개수·방향·고르기 등)에서 멈춘다. 다른 저장소의 세션에서 "확신도 90% 넘을 때까지 반복"만 주자 설계 검증을 9회차까지 묻지 않고 돌았다. 매 회차 대화를 보지 못한 새 에이전트가 판정했다. 능력은 있고, 멈추게 하는 것은 절차의 질문 지점이다.

auto 모드는 시작할 때 **목표와 끝나는 조건 두 가지만** 받는다.

- 목표가 백로그 항목이 아니면 항목을 만드는 것부터 한다.
- 끝나는 조건은 확인 방법(명령, 또는 대화를 보지 못한 검증 에이전트가 보는 확인 목록)으로 풀어 기록하고 알림만 보낸다.
- 고정할 것, 안 할 것은 미리 묻지 않는다. 사용자가 중간에 말하면 기록하고 끝까지 지킨다.
- 질문 지점에서는 스스로 정하고 `Ruling: 정한 것 — 이유 — 틀렸을 때 비용`으로 기록한다(superpowers executing-plans 의 형식). 알림은 결정마다가 아니라 묶어서(예: 항목 머지 때) 보낸다.
- 승인은 작업 세션이 아니라 상위 세션(`/lead`)이 보고를 직접 확인하고 내린다. 작성자와 판정자를 나누기 위해서다. auto 모드에서는 lead 의 "사용자의 승인을 대신하지 않는다"가 바뀐다.
- 머지는 로컬에서만, 검증 통과와 독립 리뷰 🔴 0건일 때 한다. 되돌릴 수 있는 범위에서만 스스로 정한다는 뜻이다.
- `/ui`도 묻지 않는다. 시안을 만들고 하나를 골라 Ruling 으로 남기고 이어 간다. 고른 것과 나머지 시안은 끝 보고에 싣는다.
- 꼭 묻는 것(되돌릴 수 없거나 바깥에 보이는 일)은 AC #5 에 적는다.

끝나는 조건을 채울 때까지 멈추지 않게 하는 것은 005 가 한다.

이번에 빼는 것:

- `/arch`. 사용자가 승인한 결정만 `accepted`로 적는 규칙이 있어 따로 정해야 한다.
- 제안함 승격과 scout·schedule. 웹에서 온 제안이 사람 없이 코드와 머지로 이어지면 안 된다.
- QA 역할 에이전트와 보기 화면([인수인계](_handoff-app-autopilot.md)의 나머지).
- 도구 권한 프롬프트. 권한 모드는 사용자가 정한다.
- 세션이 닫힌 뒤에도 도는 것(클라우드, 예약).

이름 "auto 모드"는 Claude Code 의 권한 모드 이름과 겹친다. 만들 때 이름을 정한다.

## Acceptance Criteria

<!-- AC:BEGIN -->

- [ ] #1 목표와 끝나는 조건만 주고 켜면, 끝나는 조건을 어떻게 확인할지 기록하고 알린 뒤 그 밖의 것은 묻지 않고 시작한다. 확인할 방법이 없는 조건이면 시작 전에 그렇다고 말한다.
- [ ] #2 목표가 백로그 항목이 아니면 항목을 만들어 진행한다.
- [ ] #3 `/task`·`/lead`·`/ui` 절차의 질문 지점이 모두 한 표에 있고, 각각 auto 모드에서 스스로 정하는지(무엇을 기준으로) 묻는지가 적혀 있다.
- [ ] #4 스스로 정한 것은 Ruling 형식으로 기록 파일과 그 항목의 Implementation Notes 에 남는다. 작업 세션은 자기 계획과 머지를 스스로 승인하지 않는다.
- [ ] #5 다음은 auto 모드에서도 멈추고 묻는다: 사용자만 아는 값, 푸시·PR 등 바깥에 보이는 일, 원격 자원 변경, 데이터·브랜치·워크트리·커밋하지 않은 변경 지우기, CLAUDE.md·권한·`.claude/` 설정 변경, 기존 테스트를 지우거나 약하게 고치기, 머지 충돌에서 어느 쪽을 살릴지 판단할 수 없을 때. 모아서 한 번에 묻고, 이미 답한 것은 다시 묻지 않는다.
- [ ] #6 머지는 검증 통과와 독립 리뷰 🔴 0건일 때만 로컬에서 한다.
- [ ] #7 `/ui`에서 시안 개수·방향·고르기를 묻지 않고 정해 이어 가고, 끝 보고에 고른 시안과 나머지 시안이 있다.
- [ ] #8 사용자가 중간에 말한 제약(예: "배포는 나중에")이 기록 파일에 적히고, 돌고 있는 작업 세션에도 전해지고, 이후 판단에서 지켜진다.
- [ ] #9 기록 파일이 있어도 `/task start`·`/lead run`의 커밋하지 않은 변경 확인에서 멈추지 않는다.
- [ ] #10 사용자가 "그만"이라고 하거나 끝나는 조건을 채웠다고 보면, 한 일·정한 것(Ruling 목록)·못 한 것을 보고하고 auto 모드가 꺼진다.
- [ ] #11 auto 모드가 꺼져 있으면 기존의 묻는 동작이 그대로다.
