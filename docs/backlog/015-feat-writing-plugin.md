## Description

사용자가 AI에게 내용을 보고하거나 설명해 달라고 할 때 사람이 잘 읽고 이해하는 글을 받게 한다. 사용자는 주제나 질문만 준다. 내용은 Claude 가 이미 있는 자료(파일, 대화)에서 찾거나 검색해서 모은다. 새 플러그인 `writing`을 만들고, 결과는 세 가지 방식으로 낸다: 글로만, HTML 파일로, 둘 다.

규칙은 조사 보고서의 근거 강도 표를 따른다. 근거가 있는 것은 짧게 쓰기, 1인칭으로 확신 밝히기, 관련 있고 정확한 출처, 정보를 빼지 않고 쉬운 말로 쓰기, 용어는 그 자리에서 설명하기다. 결론 먼저 쓰기는 랩 합의로 채택한다. 형식은 내용 유형을 조건으로 짧게 정한다(절차·비교는 목록이나 표, 설명은 문단). 불릿·헤딩·볼드를 늘리라는 규칙과 장식용 그림은 근거가 없거나 해로우니 넣지 않는다. 시각물은 독자가 검사하거나 조작할 수 있는 구조일 때만 쓴다. 보고서가 "(미검증)"으로 표시한 수치는 규칙의 근거로 쓰지 않는다.

정한 것:
- HTML은 폴더에 남는 단일 `.html` 파일이다(외부 리소스 없이 브라우저에서 열림). claude.ai 아티팩트 게시는 하지 않는다.
- 방식을 주지 않으면 글로만 쓴다.

남은 조사: GitHub의 기존 글쓰기·설명 스킬과 트렌드는 아직 보지 않았다. `start`에서 계획 전에 보고, 겹치거나 가져올 것을 계획에 적는다.

근거: `docs/backlog/references/AI 글 읽기 쉬운 구조 연구.md`, `docs/backlog/references/research_notes/AI 글 읽기 쉬운 구조 연구/`

이번에 빼는 것: 다른 플러그인(workflow 보고서 등)에 적용하기, 모든 답에 늘 적용하는 출력 스타일, 슬라이드·문서 타입, claude.ai 아티팩트 게시.
