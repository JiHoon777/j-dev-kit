## 작업 방식 (이번에 정한 것)

- 사용자에게 보이는 글은 모두 한국어.
- 하위 세션은 띄운 세션이 지휘한다. 하위 세션의 질문·승인을 사용자에게 보여 주고 답을 전하며, 끝나면 묻기 전에 확인해 보고한다. 사용자를 하위 세션으로 보내지 않는다(008 AC #14 가 스킬에 넣는다).
- 하위 세션이 돌고 있으면 부모가 턴 종료 알림을 바로 못 받는다. 하위 세션이 멈추거나 끝날 때 부모에게 SendMessage 로 알리게 한다.
- 근거 없이 정하지 않는다. 자료는 요약에 맡기지 말고 원문(글 전문, 영상 자막)을 직접 읽는다. 제안에는 출처를 단다.
- 세션 보관처럼 화면에서 무언가 사라지는 일은 하기 전에 무엇을 왜 하는지 한 줄로 말한다.
- eval 비용은 Max 구독 사용량에서 빠진다. 보고되는 달러는 API 요금 환산값이다.
- 리뷰어 eval 의 라벨 규칙: 버그가 사용자에게 일으키는 일까지 단정해야 "찾음". 원인만 짚었거나 "확인 필요"로만 적은 것은 "못 찾음". 두 가지를 함께 말하는 버그는 하나만 올바르게 짚어도 "찾음".
